# Project Roles

## 🧠 Product Owner (PO)
*   Defines the product vision and roadmap.
*   Prioritizes the backlog in `status.md`.
*   Approves features and user stories.

## 🏗️ Architect
*   Defines the technical structure (Clean Architecture).
*   Makes decisions on libraries (Room, Compose, Hilt).
*   Ensures scalability and maintainability.

## ⚙️ Lead Developer
*   Implements the core logic and complex features.
*   Conducts code reviews.
*   Manages the git repository state.

## 🧪 QA / Tester
*   Verifies features against the `1-product-brief.md`.
*   Tests edge cases (Doze mode, Reboot, Permissions).
*   Reports bugs in `status.md`.
